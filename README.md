# Правомерное использование чужих произведений в учебной деятельности

Памятка для обучающихся и работников института: порядок правомерного использования
изображений, музыки, видео и текстов при подготовке презентаций, учебных фильмов,
отчётов и мероприятий. Подготовлена на основании части четвёртой Гражданского кодекса
Российской Федерации.

## Состав репозитория

| Файл | Назначение |
| --- | --- |
| `index.html` | Инструменты: мастер проверки, генераторы, каталог источников, чек-лист |
| `spravochnik.html` | Справочный текст: нормы, понятия, лицензии, ответственность |
| `assets/styles.css` | Общие стили обеих страниц |
| `assets/tools.js` | Логика инструментов и данные каталога источников |
| `assets/reference.js` | Оглавление справочника, ссылки на пункты, подсказки на терминах |
| `images/` | Фотографии для страниц (Unsplash License) |
| `pravomernoe-ispolzovanie.html` | Ранняя редакция страницы |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |
| `Источники.txt` | Перечень использованных нормативных актов и материалов |

Данные (правила мастера, каталог источников, словарь терминов) лежат прямо в
JS-файлах, а не во внешнем JSON: так страницы работают и при открытии с диска,
где `fetch` к локальному файлу запрещён политикой браузера. Отметки чек-листа
сохраняются в `localStorage` того браузера, где их поставили.

## Как открыть

Сборка не требуется, зависимостей нет — это статическая страница. Достаточно открыть
`index.html` в браузере.

Локальный просмотр с веб-сервером (нужен, если проверяется поведение относительных путей):

```bash
python -m http.server 8000
```

Затем http://localhost:8000/

## Размещение на своём сервере

Каталог копируется целиком, абсолютных путей в разметке нет — страница работает
и в корне сайта, и в подпапке, и на отдельном порту.

```bash
git clone https://github.com/FalsedmitryV/FalsedmitriyV.github.io.git /var/www/pamyatka
```

Обновление после правок:

```bash
git -C /var/www/pamyatka pull
```
